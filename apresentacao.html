Problema & Solução Tecnológica

O recrutamento industrial rotineiramente ocorre por processos físicos ou descentralizados (triagem manual de currículos em papel, aplicação desorganizada de testes técnicos presenciais e armazenamento indevido de dados pessoais), o que eleva a lentidão, abre margem para erros e viola a conformidade com a LGPD.

O **BritaRH** é uma aplicação web unificada que automatiza o fluxo de candidatura a vagas, composto por três etapas guiadas: preenchimento de perfil, realização de teste de conhecimento de múltipla escolha e envio de currículo. O sistema avalia a pontuação dos candidatos, ranqueia-os no painel da empresa de forma automática e realiza a exclusão definitiva de seus dados confidenciais assim que a contratação é homologada.

Clean Architecture no Backend

Divisão lógica das camadas do backend para isolamento total da regra de negócio de integrações de frameworks e banco de dados:

Camada 1: Domain

Entidades puras representadas pelos modelos relacionais de negócio.

Camada 2: Usecases

Serviços executivos contendo a inteligência de negócios (cálculo de notas, purge).

Camada 3: Adapters

Esquemas de validação Pydantic e roteadores da API REST HTTP.

Camada 4: Infra

Conexões assíncronas do banco SQLAlchemy, cliente MinIO S3 e scripts de migração Alembic.

Modelagem de Tabelas

Tabela Campos Principais Relacionamentos Propósito
users id, name, email, cpf, birth_date, role 1:N com applications Armazena credenciais e dados cadastrais.
jobs id, title, area, description, status, workplace, schedule 1:N com questions/applications Armazena as vagas criadas pelo RH.
questions id, job_id, text, options (JSON), correct_index N:1 com jobs Questões dos testes vinculados a cada vaga.
applications id, job_id, user_id, score, resume_url, created_at N:1 com jobs e users Submissão dos dados e notas de candidatos.
recruiter_whitelist id, email Nenhum E-mails de administradores autorizados.
